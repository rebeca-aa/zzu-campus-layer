# 校园信息层 · campus-layer

> 把郑州大学那堆"点进去、再点进去、再找一下"的学生服务，变成**一句话就能问**的东西。
>
> 形态有三个：**浏览器扩展**（侧边栏）、**手机 PWA**（加到主屏幕）、**安卓壳**（WebView + 课前提醒通知）。
> 没有服务器，没有账号体系，数据全在你自己设备上。

[![ci](https://github.com/rebeca-aa/zzu-campus-layer/actions/workflows/ci.yml/badge.svg)](https://github.com/rebeca-aa/zzu-campus-layer/actions/workflows/ci.yml)
[![pages](https://github.com/rebeca-aa/zzu-campus-layer/actions/workflows/pages.yml/badge.svg)](https://github.com/rebeca-aa/zzu-campus-layer/actions/workflows/pages.yml)

**在线演示**：<https://rebeca-aa.github.io/zzu-campus-layer/>
（只是壳，不含任何人的数据；第一次进去要粘一次你自己的登录态，见 [登录态从哪来](#登录态从哪来)）

## 它到底解决什么问题

学校的信息在**门户（豫见郑大）、教务、图书馆、事务中心、超星**等一堆站点里，同一个事实经常要在三个地方找：

| 你想知道 | 旧做法 | 这里 |
| --- | --- | --- |
| 明天几点上课、在哪栋楼 | 门户 → 服务 → 教务 → 课表 → 缩放到今天 | 「明天有课吗」 |
| 现在哪间教室能坐两小时 | 教务 → 空闲教室 → 选校区 → 选节次 → 一格格看 | 「现在哪能坐两小时」 |
| 那门课考了多少分 | 教务 → 成绩 → 找课程 | 「高数多少分」 |
| 有没有跟我有关的通知 | 门户、教务各刷一遍 | 「今天有什么讲座」 |
| 图书馆还有位置吗 | 另开一个站点，还要登录 | 「图书馆还有位置吗」 |

它是**只读优先**的：查数据、算空闲、渲染卡片。唯一会"写"的操作（预约图书馆座位）必须你**长按 1.2 秒**确认，而且是在你自己登录的那个标签页里点，扩展不碰你的密码。

## 三种用法

| 形态 | 适合 | 能力 | 怎么装 |
| --- | --- | --- | --- |
| **浏览器扩展**（MV3） | 电脑上用（可选） | 全部 14 个工具 + 通知卡片 + 每日盯梢 | 见 [60 秒上手](#60-秒上手扩展)（没装 Node 就下 [dist.zip](https://github.com/rebeca-aa/zzu-campus-layer/releases/download/dist-latest/campus-layer-dist.zip)） |
| **PWA** | 手机（安卓/iOS 都能加主屏幕） | 除"每日盯梢"外的全部；可带模型 key | 打开 [在线演示](https://rebeca-aa.github.io/zzu-campus-layer/) → 加主屏幕 |
| **安卓壳**（可选） | 想要原生图标 + **课前 30 分钟通知** | PWA 全部 + AlarmManager 提醒（壳内嵌登录，不用再复制地址） | [**直接下载 APK**](https://github.com/rebeca-aa/zzu-campus-layer/releases/download/apk-latest/campus-layer-debug.apk)（不用登录 GitHub） |

> 手机 Chrome 至今不支持扩展（Kiwi 已停更），所以手机走 PWA；安卓壳只是把同一个 PWA 包进 WebView，顺便拿到系统通知能力。
>
> 想把它部署到自己的域名/子路径？看 [docs/deploy-pwa.md](docs/deploy-pwa.md)。**仓库里没有 `dist/`**（构建产物不入库），要么本地 `npm run build`，要么直接下 [campus-layer-dist.zip](https://github.com/rebeca-aa/zzu-campus-layer/releases/download/dist-latest/campus-layer-dist.zip) 解压。

## 60 秒上手（扩展）

```powershell
npm install --ignore-scripts   # 沙箱里必须加 --ignore-scripts，见「开发」一节的坑
npm run build                  # 产物在 dist/（这个目录不进仓库，见下）
```

> **仓库里没有 `dist/`**——构建产物不入库（避免每次提交一堆带 hash 的 chunk）。
> 两种拿法：
> - 装了 Node：上面两条命令，自己构建出来；
> - **没装 Node**：直接下 [campus-layer-dist.zip](https://github.com/rebeca-aa/zzu-campus-layer/releases/download/dist-latest/campus-layer-dist.zip)（约 110 KB，**不需要登录 GitHub**），解压就是 `dist` 的内容。
>   （另一个来源：任意一次 [pages 运行](https://github.com/rebeca-aa/zzu-campus-layer/actions/workflows/pages.yml)页面底部的 Artifacts，但那个要登录。）

1. `edge://extensions`（或 `chrome://extensions`）→ 打开「开发人员模式」→「加载解压缩的扩展」→ 选构建出来的 `dist` 目录。
2. 浏览器里登录一次 `https://jwxt.zzu.edu.cn/uniapp/index.html`（教务）和/或 `https://uniapp.s.zzu.edu.cn`（门户）。
3. 点工具栏图标打开侧边栏，顶部两枚药丸变绿就能问了。

> 票根就是 `X-Id-Token`：教务页面下发的能撑 30 天，门户页面下发的是 8 小时。
> 嫌麻烦可以在设置里只填一次学号密码（点一次「绑定」、填一条短信码），之后本机自己换 30 天的票，过期了重新打开页面也会自动续。

## 能问什么

**课表 / 自习**

| 说法 | 做什么 |
| --- | --- |
| 「明天有课吗」「第 8 周课表」 | 按天/按周列课，带教室和教师；答案下面附一张校园地图（可选） |
| 「今天下午我有课吗」 | 按时段收窄，只列那个时段的课 |
| 「下周课表」「上周三有课吗」 | 相对周次（0=本周、1=下周、-1=上周）；**按天问时周次跟着那一天走**——周日晚上问「明天」不会再用本周的周次去筛 |
| 「明天南核空教室」 | 全部教室 − 当天占用；**认地点词**：南核/北核/北1/物理馆/材料馆/图书馆 |
| 「明天上午哪间教室能坐两小时」 | 给每间教室的**连续空闲窗口**（`08:00–12:00`、`现在就能坐 2 小时 40 分`） |
| 「我想自习两小时」 | 教室 + 图书馆合成一个入口，按时长和步行距离排序；凑不够会分级说「这个只能坐 1 小时」 |

**通知**

| 说法 | 做什么 |
| --- | --- |
| 「今天有什么讲座」「这周有比赛吗」「挑战杯什么时候截止」 | 通知**卡片**：讲座/比赛/活动/会议/教务/生活六类（教务再细分选课/考试/成绩/学籍/毕业/论文/实习），每条带开讲时间、地点、报名截止；可筛分类/时间窗、按发布或截止排序 |
| 「查一下 XX 的通知」 | 教务通知（完整正文）+ 门户通知（摘要）；口语话题自动扩同义词（比赛 → 竞赛/大赛/挑战杯） |

**成绩 / 学分 / 一卡通 / 待办**

| 说法 | 做什么 |
| --- | --- |
| 「我这学期绩点多少」「高数多少分」 | 成绩/考试列表；可按课程名过滤，带出服务端给的构成分（平时/期中/期末/卷面——有什么给什么） |
| 「我还差多少学分毕业」 | 按模块列要求/已通过/在修/还差，带进度条 |
| 「我卡里还有多少钱」「最近消费」 | 一卡通余额 + 最近流水 |
| 「有什么要办的事」 | 待办/在办/待申请计数，紧急与超时单独标出 |

**图书馆**

| 说法 | 做什么 |
| --- | --- |
| 「图书馆还有位置吗」 | 各馆实时空闲/总数（免登录），带楼层明细和百分比 |
| 「一楼大厅哪些座位空着」 | 座位级空闲号 + 按坐标画一张平面图（绿点空、灰点占，每个空座标号） |
| 「帮我订 001」 | 生成**长按 1.2 秒**的确认按钮；确认后才在你自己的页面里点座位、点预约、点确认，并按页面反馈如实回报 |

**约上了还是没约上，面板会给三种不一样的结果气泡**（`src/core/libBook.ts` 判定、`src/ui/toast.tsx` 渲染）：

| 气泡 | 什么情况 | 你会看到 |
| --- | --- | --- |
| 绿 ✓「约上了」 | 抓到系统对 `POST /v4/space/confirm` 的成功回执，**并且**回读座位图显示这个座位已经不是空闲 | 座位号 + 「已经约上，系统回了成功回执」 |
| 黄 ?「结果存疑」 | 接口说成功，但座位图还显示空闲；或者只看到页面提示、没抓到回执 | 明确写着「先别当成约上了，去『我的预约』看一眼」 |
| 红 ✕「没约上」 | 系统回错误码 / 座位被占 / 「立即预约」是灰的 / 没等到确认弹窗 / 页面没回应 | 座位号 + 系统原话（例如「该座位已被预约」） |

三种的图标、左边色条、标题都不一样，不会看混；气泡 5～9 秒后自己消失，点右上角 × 也能关。光靠页面上的「预约成功」四个字不算数——那正好是以前误报的原因。


**其它**

| 说法 | 做什么 |
| --- | --- |
| 「打开座位预约」「报修在哪」「食堂怎么订餐」 | 从 19 项门户服务里认出你要的，给官方入口（面板里是可点按钮） |
| 「把课表导出成日历」 | 生成带 `Asia/Shanghai` 的 `.ics` |

**不用问的（自动）**：每天后台跑最多 3 次，盯「新出成绩」和「7 天内截止的报名/申请类通知」，一条截止一条系统通知，点开直接定位到那张卡；同一条不重复推；首次运行不刷历史。

**手机端界面**：底部四栏——**主页 / AI / 学期课表 / 我的**。

| 栏 | 里面有什么 |
| --- | --- |
| 主页 | 今日课表（点节次那行能看整周）+ 三个入口（图书馆 / 空教室 / 校园卡）+ 最新一条通知；全部通知点右上角铃铛 |
| AI | 对话：常用语药丸、输入框，回答里该出图出图、该出按钮出按钮 |
| 学期课表 | 整周表格，`‹ 第 N 周 / 共 19 周 ›` 左右翻，日期跟着走，今天那列高亮 |
| 我的 | 账号 / 图书馆登录 / 立即续期 / 课前提醒 / 外观 / 设置 / 关于 |

**界面动效**：二级页（账号、通知、外观、设置、关于）从右侧滑入、返回时从左滑回（260ms，`cubic-bezier(0.22,0.61,0.36,1)`），不再是硬切；系统开了「减少动态效果」时自动关掉动画。对话区里自己的气泡是白底、回答沿主题底色，翻旧记录左右一眼分得清。

**配色**：「我的 → 外观」里可切**米白 / 藏青 / 蓝绿**三套（扩展侧栏里还在右上角「登录态」面板）。后两套共用同一副深色骨架，只换一组 CSS 变量（`pwa/style.css` 里 `html[data-theme='ink'|'teal']`）：藏青是黑底 + 蓝，蓝绿是墨绿底 + 蓝绿。换完记在本机，重开还在；状态栏颜色也跟着走。

> **没有模型也能用。** 意图是规则（`src/core/intent.ts`），回答是模板（`src/core/render.ts`）。模型是可选增强，不是前置依赖。
>
> 规则没接住的口语，还有一层**离线说法库**兜底（`src/core/phrases.ts` + `src/core/utterance.ts`）：340 多条「人话 → 工具」的对照，用字符覆盖率 + 2/3 字片段相似度打分，`≥0.62` 直接执行、`0.42–0.62` 只当候选。它只在**没配模型**且正则没命中时才跑，所以配了 key 的人行为一点没变；参数不合法（比如订座缺座位号）宁可当没听懂也不乱跑。常见 64 句口语现在 63 句能接对。

**输入框上面那排常用语可以自己改**：点末尾的「+」展开面板，能加自己的话（比如「图书馆还有座吗」）、按 ↑ ↓ 调顺序、删掉用不上的，也能一键恢复默认。手机上横滑，桌面侧栏里换行排；改动存在本地（扩展 `chrome.storage.local`，PWA `localStorage`），刷新后还在。上限 12 条，重复和空内容会当场提示。

**聊天只留最近 10 条，但换页面回来还在**：聊完的记录会落到本地（`src/core/transcript.ts`），刷新、点进图书馆预约再返回、关掉侧栏重开，最近 10 条都还在（我发的和他回的一起算 10 条），不用重打一遍；回来直接停在最底部那条，没有「滑下去」的那段动画。只留 10 条是界面上的事，跟模型能看多少无关——真正发给模型的历史一直由 `src/core/agent.ts` 的 `MAX_HISTORY` 管，聊再久也不会把上下文撑满。座位图、`.ics` 这类大字段不进存档，避免把本地存储撑爆。

**更新由用户点头，不再偷偷换页**：Service Worker 装好新版本后**停在 waiting**（`public/pwa/pwa-sw.js` 里 `install` 不再 `skipWaiting()`，只留 `message` 监听），页面弹一张「新版本已就绪」的卡片，写清这次改了什么（内容来自 `public/version.json` 的 `notes`），用户点「立即更新」才 `postMessage({type:'SKIP_WAITING'})`，收到 `controllerchange` 再刷新；点「稍后」就压着，下次打开还会问。刷新到新版本后第一次运行，如果 `localStorage` 里记的版本比当前旧，会再弹一次「已经更新到 vX.Y.Z · 这次改了这些」的公告，点「知道了」关上（`pwa/update.ts` 里 `shouldAnnounce()` 管这个判断，`SEEN_KEY='seenVersion'`）。

> **发版时要改两个地方**：`package.json` 的 `version` 和 `public/version.json` 的 `version`，两个必须一致——`test/update.test.ts` 里有一条专门断言这件事，漏改会直接测试红。`version.json` 的 `notes` 写这一版新加了什么（最多 6 条），公告里原样显示。

## 模型（可选）

规则层先跑（免费、几十毫秒、离线可用）。模型怎么参与，取决于服务商**支不支持 function calling**：

| 模式 | 谁在用 | 模型干什么 |
| --- | --- | --- |
| **Agent 循环** | DeepSeek 官方 / 硅基流动 / 百炼 / Moonshot / OpenRouter | 自己决定调哪个工具、传什么参数 → 拿到真实 JSON 后自己组织回答；一轮不够可继续调（最多 4 步） |
| **判意图** | 学校 DeepSeek（Open WebUI 不暴露 tools） | 只输出 `{tool,args}`，正文由模板渲染 |

护栏写在提示词里：只许用工具返回的内容、不许编数字/课程名/通知标题、相对日期不许自己换算（由用户原话覆盖）、预约报名必须本人操作只能给入口。

界面上会显示这轮调了哪些工具（`模型编排 · find_free_room`），出问题一眼能看出是没调工具还是调错了。追问也能接住——面板和手机版都会带上最近 3 轮对话。

| 预设 | 接口 | 默认模型 | 前提 |
| --- | --- | --- | --- |
| 学校 DeepSeek | `http://chat.zzu.edu.cn/api` | `DeepSeek-R1` | 只在校园网/VPN；页面必须是 http（HTTPS 会被混合内容拦） |
| DeepSeek 官方 | `https://api.deepseek.com` | `deepseek-chat` | 自己的 key，HTTPS 可用 |
| 硅基流动 | `https://api.siliconflow.cn/v1` | `Qwen/Qwen2.5-7B-Instruct` | 同上 |
| 阿里百炼 | `https://dashscope.aliyuncs.com/compatible-mode/v1` | `qwen-plus` | 同上 |
| Moonshot | `https://api.moonshot.cn/v1` | `moonshot-v1-8k` | 同上 |
| OpenRouter | `https://openrouter.ai/api/v1` | `deepseek/deepseek-chat` | 同上 |

代价：非推理模型一次 0.5–2 秒（约 ¥0.001/次）；学校 R1 走老模式，11–25 秒。判断不了就回落成反问，并在气泡下面写清原因（401/402/403/404/429 各有说法）。

## 现在到哪了（阶段性成果）

一句话：**在手机上点开就能问自己的课表、空教室、通知、学分、一卡通、待办，还能订图书馆座位——数据全走学校自己的接口，没有服务器、不碰你的密码。**

已经闭环的东西：

| 能力 | 状态 | 备注 |
| --- | --- | --- |
| 课堂表 / 空教室（含「这间能坐多久」） | ✅ 实网跑通 | 空教室 = 全部教室 − 当天占用，按 379 间真实上课教室筛 |
| 自习决策器（「我想自习两小时」） | ✅ | 教室 + 图书馆座位一起排，带楼间步行时间 |
| 通知总入口（六类分类、只读标记） | ✅ | 合并自同学 PR #1 |
| 成绩 / 学分 / 一卡通 / 待办 | ✅ | 大一当前无成绩时如实说「没数据」 |
| 图书馆实时空座 + 座位图（SVG 标号） | ✅ 扩展 / 网页 / 壳 | 楼层与区域 id 现查服务端楼层表；回答里写明「实际用的日期 + 区域」 |
| 图书馆座位**下单** | ✅ 安卓壳（长按 1.2 秒） | 壳里用已登录的 WebView 让页面自己发 `confirm`（含 AES），我们不碰密码；电脑扩展走同一套 DOM 驱动 |
| 课前 30 分钟提醒 | ✅ 安卓壳 | 每节课各弹一条（不合并） |
| 每日盯梢（出分 / 截止） | ⚠️ 有实现 | 成绩接口当前为空、通知正文常被压成标题，暂时推不出东西 |
| 手机取登录态 | ✅ 已解决 | CAS 登录 → 地址栏带 ticket → 粘贴即导入（见下节） |

明确做不到的（不是没做，是数据/权限不在手上）：一卡通消费分类（接口只给深链）、通知全文（门户 CMS 硬截 200 字）。座位**下单**能在壳里做，但必须由你本人长按确认——我们不代你决定，也不存你的图书馆密码。

## 装安卓壳（可选）

1. 手机点这个链接下载（**不需要登录 GitHub**）：
   <https://github.com/rebeca-aa/zzu-campus-layer/releases/download/apk-latest/campus-layer-debug.apk>
2. 打开安装包 → 系统会拦一下「未知来源应用」，允许你的浏览器/文件管理器装即可。
3. 首次打开点右上角菜单 **「登录（推荐）」**——壳里会用学校账号登录，登录完自动回到主界面并把登录态灌进去，**不用再复制地址、不用同步码**。
4. 装完能在系统里收到课前提醒：**每节课开课前 30 分钟各弹一条**（连堂课也各自提醒，不合并）。
5. 想查图书馆座位号，先点右上角菜单 **「登录图书馆」** 登一次（那是它自己的一套账号密码，跟学校 CAS 是两个系统）；之后直接问「图书馆一楼座位表」即可，壳里走原生 HTTP，**不需要开着网页**。
6. 想订座就说「订 001，明天」，会给你一个 **长按 1.2 秒** 的确认按钮——长按才真的提交，松手取消。

> 这个 APK 是 CI 每次 push 到 main 自动构建的调试包（没有正式签名），想自己构建见 [`mobile/android`](mobile/android)。壳内登录若哪天失灵，还有两条备选：菜单「从剪贴板导入」（在外面复制带 `ticket=` 的地址）与「用系统浏览器登录」。

## 登录态从哪来

学校没给外部应用开 OAuth，所以「我们自己的壳 / 网页」拿不到登录态；能走的只有两条：

### 办法一（推荐）：用学校账号登录，然后把地址复制回来

1. 点「打开学校登录页」（去的是**统一身份认证**，不是树维那个登录页），用学号 + 密码登录。
2. 登录成功后会跳到**一屏代码/样式文本**——这是故意的，不用管它长什么样。
3. **长按地址栏 → 复制整条网址**，回来粘到输入框里保存。跳到 404 或空白页也照样复制。
4. 如果新开的页面里**没有地址栏**（应用内跳转常见）：
   - 点「复制登录页链接」，粘到自己手机的浏览器里打开，再走第 2、3 步；
   - 或者直接装**安卓壳**——壳里点菜单「登录」，登录完自动灌进来，全程不用复制。

> 一次导入能用 30 天（教务票的有效期）。过期后重复一遍即可。

### 登录态能撑多久（以及为什么不能「永久」）

学校里两张票的有效期不一样，机制上也拿不到「长期凭据」：

| 票 | 有效期 | 谁在用 |
| --- | --- | --- |
| 教务 `idToken` | **30 天** | 课表、成绩、空教室、校历 |
| 门户 `userToken` | **8 小时** | 通知、一卡通余额、待办 |

现在有四级兜底（越靠前越省事）：

1. **账密直换 30 天**（0.2.71 起）：设置里填一次学号密码（手机 App 里就能走完短信验证，不必开电脑），之后就由本机用学校 App 的 `/token/` 接口换票。`deviceId` 过一次短信后成了可信设备，此后**纯账密、~100 ms 拿一张 30 天的票**，eams-door 与门户 `portal-api` 都认（同一张票两处通用）。不用浏览器、不用 TGC、不用定时任务。
2. **两张票互顶**：没填账密时，门户票失效会拿还在有效期内的教务票重打同一接口（两张同为 `cas.s.zzu.edu.cn` 签发）；不认账就记 6 小时，不再来回试。
3. **自己续（CAS）**：桌面扩展在后台开一个**不抢焦点**的标签页走一趟 CAS（浏览器里 CAS 会话还在就带新票回来）；扩展里还多一条纯 `fetch` 快路（靠 `host_permissions` 带 cookie，一条请求换 8 小时票）。安卓壳同样有 Java 快路，且优先走第 1 条。
4. **勾「记住我」**：CAS 会话能活 14 天，是上面 CAS 那两条的前提。

手机 PWA 没有扩展：要么填账密（走第 1 条，壳里执行），要么靠 30 天的教务票。换设备/清数据/学校强制下线才需要重新登一次。

### 办法二：「豫见郑大」App 分享链接（鸿蒙版）

App 里任意页面 → 分享 / 复制链接 → 粘到下面。

- 鸿蒙版实测可用；**安卓版 App 自带的「复制链接」是坏的**（剪贴板没变化），可以试系统级分享（长按页面 / 发到微信再复制）。

### 也能收的其它形态

同步码 / 分享码（`#code=…`）、以 `eyJ` 开头的裸 token、带 ticket 或 idToken 的整条网址——粘进来都能用（只是不再推荐「先去电脑上弄一个」：教务在电脑浏览器里常常登不进去）。

## 隐私与安全

- **没有服务器。** 请求从你的浏览器直接发往学校域名（以及你自己选的模型服务商），中间没有本项目的中转。
- **令牌只在本地。** 存在 `chrome.storage.local`（扩展）或 `localStorage`（PWA/壳）。同步码是 **base64 编码，不是加密**——等同登录态，别发到群里。
- **模型 key 的权限**等于你在那家服务的使用权，不含密码、不含教务/门户权限。可以随时在服务商后台重置。
- **只读优先。** 唯一的写操作（图书馆预约）需要长按确认，且在你自己登录的页面里执行。
- **权限**：15 个域（8 个学校域 + `http://chat.zzu.edu.cn/*` + `http://order.lib.zzu.edu.cn/*` + 5 家模型服务商），不申请 `<all_urls>`。API 权限 `storage, alarms, sidePanel, scripting, notifications`——`scripting` 只用来读你自己那个图书馆标签页的 `sessionStorage.token`。

## 它是怎么做到的

不走"抓网页"：门户和教务都是 uni-app 的 SPA，DOM 没有稳定语义，`nth-child` 一改版就漂。这两套系统的 App 和网页**共用同一份代码**，只靠 `X-Terminal-Info` 区分渠道——所以只要拿到 `idToken`，能做的事和官方 App 完全一样，还比解析 DOM 稳。

```
CAS 登录 ──> idToken (JWT)
              │
   ┌──────────┴───────────┬───────────────┬──────────────┐
   ▼                      ▼               ▼              ▼
门户 portal-api      教务 eams-*     事务中心 ttc    图书馆 v4
课表/节次/CMS通知    课表/成绩/教室/  待办          馆级余量（免登录）
一卡通             培养方案/通知                   座位图（需页面登录）
   │                      │               │              │
   └──────────┬───────────┴───────────────┴──────────────┘
              ▼
      services.ts（缓存 + 降级）→ tools.ts（14 个工具）
              ▼
      intent.ts（规则，几十毫秒）→ 命中就出答案
              │ 没命中
              ▼
      utterance.ts（离线说法库，只在没配模型时）→ 分数够且参数合法才执行
              │ 还是没命中
              ▼
      llm.ts（可选）：agent 循环 or 判意图 → render.ts 模板渲染
```

更多细节：[平台架构](docs/campus-platform-architecture.md)、[接口实测](docs/campus-site-probe.md)、[服务盘点](docs/portal-services-inventory.md)、[通知卡片规则](docs/notice-hub.md)。

## 已知限制（诚实版）

**数据本身**

- **成绩**：接口通，但大一当前学期无数据（`data: []`）；构成分（平时/卷面）只能"有什么给什么"，各课字段还不一样，试卷级明细不在任何接口里。
- **一卡通**：只有余额 + 最近流水；**分类统计做不到**——真正账单在 `ecard.v.zzu.edu.cn`，要单独登录。
- **通知全文**：教务侧完整 HTML 可得；门户 CMS 的 `content` 被服务端硬截 200 字，官网原文需登录，不抓。
- **通知的时间/地点/截止是抽出来的**，不是接口给的：抽不到就不显示（宁缺不猜），截止提醒只对正文含明确日期的通知生效。
- **座位状态**：只认 `status_name`；纯数字编码按未知处理（猜错会把占座当空座）。实测 `1=空闲、6=使用中`。
- **座位图是自己按坐标画的**，不是官方那张：没有桌椅门窗，只有"绿点空/灰点占 + 空座标号"。整张图等比缩放、宽高等比装得下，不裁切；标号只在**不会压到任何座位点**的位置出现，挤不下就少标几个（图头写着 `标号 57` 这种就是标了多少个），文字版仍会列出空座号。
- **二层以上一层里有多间自习室**：每间的坐标是自己那套，混在一张图上会叠成一团。所以按楼层问的时候，回答会先把这一层的房间逐间列出来（空 x / 共 y），图里每间一块、块头写着房间名；点名房间（「二楼 A 区座位图」）就只画那一间。座位号按**房间内**去重，不同房间重号不会被吃掉。

**能力边界**

- **模型**：只有支持 function calling 的服务商能进 agent 循环；学校那把只能判意图。HTTPS 页面调不了学校 AI（混合内容），会就地提示换服务商。
- **图书馆预约**：该站只有 http、仅校内网。**电脑扩展**要开着已登录的标签页（走 content script 点页面）；**安卓壳**走原生 HTTP + 已登录 WebView，不需要标签页。我们不复制它的 AES 加密，而是让页面自己发请求。
- **图书馆同一时间只允许一台设备在线**：在别处登录会把这台顶掉，表现为座位图报 `code=10001 … 已从其他设备上登录` —— 点「登录图书馆」重登一次即可。余量接口免登录，所以被顶掉时「还有多少位置」仍然正常，只有座位号读不到。
- **图书馆的区域 id 因馆/楼层而异**（主校区一楼是 `2`，不是页面里出现过的 `3`），所以我们改成每次从服务端 `storey` 表现查；服务端只接受**今天/明天**两天，其它日期回 `code=610 … 座位已被预约或未开放`，我们会先把日期夹进这两天再问。
- **未读消息**：`message-service` 的未读数接口回 500，暂不做。

**性能**

- 空教室：全校 379 间可上课教室，一次约 4 秒（小页 + 12 路并发），之后 60 秒缓存。
- 座位图：216 座约 20 KB 的 SVG（data URI），只在出图时生成。

## 进展记录（2026-10-27）

这一版把「图书馆座位」从演示级做到了能用，并把手机端的更新链路修通了。

**图书馆座位（本轮重点）**
- 工具参数从「数字区域 id」改成**语义参数**：`floor: '一楼'|'二楼'|'三楼'|'四楼'` + `room: '语言文史书库'`，模型不用记 id，也就不会再把「二楼」算成别的楼层。
- 楼层 → 房间 id 用实测表（`src/core/library.ts`）：一楼 `3`；二楼 `8/9/11/12`；三楼 `13–17`；四楼 `18/19/20/76`。
- 问**楼层**：整层展开，每间一行余量 + 每间一张座位图（`data.images`）。
- 问**房间**：只读那一间、只画那一张。判据三级：`room` 字段 → 用户原话里的房间名（前 4 字模糊匹配）→ `areaId` 已是具体房间就不再展开。
- 修掉三个「id 被吞」的真 bug：`areaCandidates` 把楼层默认间排在前面、`libtab` 把房间 id 归一成楼层默认间、楼层备选表里塞了楼层级旧 id（会多出「区域 72」这类未命名项）。
- 日期不再信模型：早先靠 `/v4/space/index` 拿「今天/明天」，被混合内容拦下后会把旧日期发出去 → 馆站只认今明两天，其余一律 `code=610`；现在改成本地按 Asia/Shanghai 算。
- `code=610`（该区域当天不可约）与 `code=10001`（被别的设备顶掉）分开展示；桥路径还有「今天不行就试明天」的兜底。

**界面**
- 长按预约按钮：宋体 + 按住后**红色进度条从左端跑到右端**，跑满 1.2 秒才提交，松手立即取消。
- 蓝绿（teal）配色：模型气泡由白底改成同族墨绿不透明面，正文近白、去掉半透明，解决「白底浅字看不清」。
- 面板顶部显示**前端版本号**（当前 `0.2.52`），用来判断手机上有没有拿到新前端。

**版本与更新链路（踩过的坑）**
- `public/pwa/pwa-sw.js` 缓存名已到 `campus-layer-v8`，并加了 `skipWaiting` + `clients.claim`；注册用 `{ updateViaCache: 'none' }` + 每次 `reg.update()`，新 SW 装好后自动 `reload` 一次。
- 安卓壳在**版本号变化**时执行一次 `web.clearCache(true)`（不动 cookie/localStorage），所以「装了新 APK 但界面还是旧的」这个坑关掉了；反过来，**只推前端不发 APK 时**，必须杀进程重开才会用新缓存名。

**仍然做不到 / 已知边界**
- 图书馆座位图依赖那个站自己的登录态（`order.lib.zzu.edu.cn`，与学校 CAS 是两套账号），且**同一时间只允许一台设备在线**。
- 一层一次问会发 4–5 次请求（每间一次），手机上 2–4 秒。
- 下单只到「长按提交再由页面自己发」这一步；AES 加密的 `/v4/space/confirm` 不复刻。

非官方项目，与郑州大学及超星/树维等厂商无隶属关系。它查的是**你自己的账号、你自己的数据**。

## 贡献

欢迎 PR，三条要求：

1. 别提交任何 token、`sk-` key、学号姓名、未脱敏的原始响应。
2. 新增能力前先读 [docs/portal-services-inventory.md](docs/portal-services-inventory.md)——哪些服务现实中接不上、为什么。
3. 跑一遍 `npm run verify`；能动 UI 的话再跑 `npm run e2e` 与 `npm run pwa:shot`。
